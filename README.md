# 차곡차곡 수학 · 4학년 2학기

학생은 **학급 코드와 번호만** 사용합니다. 학생 이름을 수집하거나 저장하지 않습니다.

## 기능

- 5회차 × 20문항 = 100문항
- 회차마다 1~5단원 각 4문항, 하 6·중 8·상 6문항
- 서버 자동 채점, 오답만 재도전, 학생에게 정답·해설 미제공
- 학생: 회차별·누적 취약 단원과 남은 오답 확인
- 교사: 첫 점수·최근 점수·제출 이력·문항별 최초 오답률·CSV 다운로드
- 빈 학습지 A4 인쇄

## 배포

대상 저장소: https://github.com/rldusovuun/math_review_grade4

**GitHub는 소스 저장과 자동 배포, Cloudflare Workers는 웹사이트·채점 서버, D1은 학습 기록 저장을 담당합니다.** GitHub Pages만으로 이 앱을 실행할 수는 없습니다.

[처음 배포하는 방법](DEPLOY.md)을 따라 설정합니다. 교사 주소는 배포된 주소 뒤에 `/teacher`를 붙입니다.

## 로컬 개발

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm test
npm run db:local
npm run dev
```

교사 로그인을 시험하려면 `.dev.vars.example`을 `.dev.vars`로 복사하고, 16자 이상 비밀번호의 SHA-256 값을 `TEACHER_PASSWORD_SHA256`에 넣습니다. 실제 비밀번호·해시·토큰을 Git에 올리지 마세요.

## 데이터와 계산 기준

- 학급 내부에서 번호로 식별합니다. `01`과 `1`은 같은 번호입니다.
- 첫 제출은 20문항 모두 답해야 가능합니다. 문항당 5점입니다.
- 재도전은 남은 오답만 입력합니다. 해결한 문항은 유지하고 첫 점수는 바뀌지 않습니다.
- 최초 오답률 = 처음 틀린 학생 수 / 해당 회차 첫 제출 학생 수 × 100
- 미제출 학생은 오답률 분모에서 제외합니다. 재도전은 최초 오답률을 바꾸지 않습니다.
- 학생 취약 단원은 최초 오답 수를 비교합니다. 동률이면 모두 표시합니다.
- 학급 코드를 재발급하면 기존 세션은 무효화되지만 결과 기록은 남습니다.
- 학급 코드와 번호가 같으면 같은 학생으로 처리합니다. 번호 소유자 본인 인증은 하지 않습니다.
- 학생 답안·학급 코드·교사 비밀번호를 저장소에 올리지 않습니다. 학습 기록은 D1에 저장됩니다.

## 주요 파일

- `lib/questions.mjs`: 100문항 및 교사용 정답·해설 (서버에서만 사용)
- `lib/core.mjs`: 채점·집계
- `app/api/math/route.ts`: 세션·제출·교사 조회 API
- `drizzle/*.sql`: 추가 방식의 DB 마이그레이션
- `.github/workflows`: 검사와 배포
